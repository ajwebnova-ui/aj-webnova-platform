# AJ Webnova AI Growth Engine
A high-ticket lead conversion system powered by GLM-5.3-Flash.

## 🚀 Project Overview
This system automates the process of identifying high-value business leads and converting them into premium clients by using a three-agent architecture:
1. **The Hunter:** Filters low-budget clients and identifies high-ticket opportunities.
2. **The Analyst:** Performs rapid technical audits of client websites to find "revenue killers."
3. **The Closer:** Converts technical flaws into high-converting, high-ticket proposals.

## 🛠️ Setup Instructions

### 1. Installation
Ensure you have Python 3.9+ installed.
```bash
pip install openai python-dotenv
```

### 2. API Configuration
Create a `.env` file in the root directory:
```env
NVIDIA_API_KEY=your_nvapi_key_here
```

### 3. Running the Engine
Run the main execution script to process a lead:
```bash
python main.py
```

## 📈 Revenue Goal: 40k/Day
This engine is designed to shift AJ Webnova from "hourly freelance work" to "value-based corporate consulting." By providing a free audit (Analyst) and a strategic solution (Closer), we increase the average project value from 2k to 20k+.
